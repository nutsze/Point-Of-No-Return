# Ten Winters

Визуальная новелла о десяти годах российской истории — с августа 2020-го
до 2030-го. Обычный человек, который «не интересуется политикой», шаг за
шагом оказывается внутри этой истории: протесты, запреты, война,
мобилизация, доносы, тюрьмы, смерть Навального — и то, что могло бы
случиться потом.

События до 2026 года — документальная основа со ссылками на источники.
2027–2030 — вымысел.

## Запуск

Готовый `TenWinters.exe` для Windows лежит во вкладке **Releases**.

Из исходников (Python 3.10+):

```bash
pip install -r requirements.txt
python3 main.py
```

Управление: мышь или 1–9 / стрелки / Enter. Пробел — показать текст
целиком или пропустить титры. **F11** — полный экран на родном разрешении
монитора (поддерживаются 1080p, 1440p, 4K — вёрстка считается от реальной
высоты окна). **M** — звук. **Esc** — пауза.

Прогресс сохраняется после каждого выбора в `~/.ten_winters_save.json`.

## Что внутри

- **12 глав**, около 70 сцен, 8 концовок — три из них заканчиваются
  титрами «Вы победили». После любой концовки — эпилог «Что было
  дальше»: судьба брата, Марины, мамы, твоей работы или учёбы и
  организации складывается из конкретных решений по ходу игры.
- Подача визуальной новеллы: фото на весь экран в каждой сцене, текст
  в плашке снизу, страницами.
- Сцены работы и учёбы свои для каждой профессии: студента не
  увольняют, а отчисляют; учителю спускают «урок о важном».
- Давление: звонок из «Центра Э», визит полиции к маме, адрес в
  Z-канале, машина под окнами — в зависимости от того, насколько
  ты заметен.
- Герой — твоё имя, пол, профессия и один из десяти городов; текст
  склоняется под них.
- **Выбор, с кем идти**: ФБК и штабы Навального, «Яблоко», КПРФ как
  системная оппозиция через «Умное голосование», «Весна», ОВД-Инфо,
  антивоенная диаспора. У каждого пути свой риск.
- Скрытые показатели: «голос» (насколько громко ты говоришь и действуешь)
  и «риск» (насколько ты заметен для силовиков). При высоком риске будет
  обыск и срок; если довериться не тому человеку — донос.

### Реальные люди

Реальные люди **не произносят в игре выдуманных реплик**. Они появляются в
новостях, в досье «Кто эти люди» и в финальных титрах, а говорят только
через подлинные цитаты с указанием, где и когда это было сказано:

| Цитата | Кто, где |
|---|---|
| «Был Александр Освободитель и Ярослав Мудрый. А будет Владимир Отравитель трусов.» | Алексей Навальный, Симоновский суд, 2 февраля 2021 |
| «Я знаю и то, что настанет день, когда мрак над нашей страной рассеется.» | Владимир Кара-Мурза, последнее слово, апрель 2023 |
| «Я буду продолжать дело Алексея Навального.» | Юлия Навальная, видеообращение, 19 февраля 2024 |
| «Вам нельзя сдаваться.» | Алексей Навальный, фильм «Навальный» (2022), в оригинале “You're not allowed to give up” |

Перед публичным релизом стоит ещё раз сверить дословность цитат с
первоисточниками.

## Ресурсы и лицензии

- **Фото** — только свободные лицензии с Wikimedia Commons (CC BY, CC BY-SA,
  CC0, public domain). Автор и лицензия выводятся в игре под каждым фото и
  в досье; полный список — `assets/photos/credits.json`.
- **Шрифты** — Oswald, PT Serif, PT Mono (SIL Open Font License),
  см. `assets/fonts/README.md`.
- **Музыка** — оригинальная, синтезирована кодом (`tools/make_audio.py`),
  без чужих записей и семплов.

Пересобрать ресурсы:

```bash
pip install pillow numpy
python3 tools/fetch_photos.py     # медленно: Wikimedia ограничивает частоту запросов
python3 tools/process_photos.py
python3 tools/make_audio.py       # нужен ffmpeg для OGG
```

## Структура

```
main.py                точка входа
engine/story.py        сюжет: главы, сцены, выборы, концовки, досье
engine/state.py        состояние героя, склонения, сохранения
ui/app.py              интерфейс на pygame
assets/                шрифты, фото, музыка
tools/                 загрузка и обработка фото, генерация музыки
tests/                 граф сюжета, достижимость концовок, склонения
```

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют, что из каждой сцены есть путь дальше, все сцены и все
восемь концовок достижимы, эпилог собирается для любого прохождения,
у студента в тексте не появляется «работа», у каждой цитаты указан автор и источник, а
подстановки имени/пола/города/профессии не оставляют в тексте «дыр» ни
для одной комбинации.

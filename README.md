# Точка невозврата

Текстовая визуальная новелла на чистом Python (стандартная библиотека,
никаких зависимостей). Вымышленный герой проживает реальную политическую
историю России 2020–2030 (2027–2030 — предположительное будущее) и
постепенно, через конкретные выборы, из аполитичного человека превращается
в того, кто либо вступает в политику, либо остаётся в стороне.

## Запуск

```bash
python3 main.py
```

Python 3.10+, без установки пакетов. Прогресс автосохраняется после
каждого выбора в `~/.point_of_no_return_save.json`.

## Как устроен сюжет

- Игрок называет себя: имя, профессию, город.
- История начинается в августе 2020 года, за несколько дней до отравления
  Алексея Навального, и идёт по реальной хронологии: возвращение и арест
  в январе 2021-го, вторжение в Украину в феврале 2022-го, мобилизация,
  гибель Навального в феврале 2024-го, обмен заключёнными в августе
  2024-го — и дальше в предположительное будущее до 2030 года.
- На ключевых развилках герою прямо предлагают **вступить в партию
  «Яблоко»** — настоящую, легально действующую оппозиционную партию —
  либо остаться сторонним наблюдателем.
- Отдельная сюжетная линия про доверие: один из близких героя может
  оказаться информатором, и это выясняется не сразу.
- Выборы копятся в двух параметрах (`voice` — готовность говорить и
  действовать, плюс флаги `joined`/`left`/`betrayed`) и определяют одну
  из четырёх концовок.

### Реальные люди в игре

Алексей Навальный, Юлия Навальная, Владимир Кара-Мурза, Илья Яшин,
Григорий Явлинский, Борис Немцов, Анна Политковская, Наталья Эстемирова —
упоминаются только как новостной фон и исторический факт (с указанием
источника/даты события) либо в финальных титрах-посвящении. **Ни один из
них не произносит в игре вымышленных реплик** и не является управляемым
или разговаривающим персонажем — это принципиальное ограничение движка,
закреплённое в `engine/story.py`.

### Концовки

| Концовка | Условие |
|---|---|
| **«Вы победили»** | высокий `voice`, не предан(а) — показываются титры-посвящение |
| **«Издалека»** | уехал(а) и не стал(а) частью движения |
| **«Цена»** | был(а) предан(а) при высокой вовлечённости |
| **«В стороне»** | низкая вовлечённость на протяжении всей истории |

## Структура

```
main.py              — точка входа
engine/
  story.py            — граф сюжета: узлы, выборы, концовки, досье реальных людей
  state.py             — состояние игрока, сохранение/загрузка
  game.py              — терминальный раннер (ввод/вывод, экран титров)
tests/
  test_story.py         — граф без тупиков, все узлы достижимы, логика концовок
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

11 тестов: целостность графа (все `next` ведут на существующие узлы или
на финал), достижимость каждого узла от старта, корректность форматирования
плейсхолдеров `{name}/{prof}/{city}`, логика выбора концовки по накопленным
флагам.

## Расширение сюжета

Новый узел — это запись в словаре `NODES` в `engine/story.py`:

```python
"my_node": dict(
    date="...", place="{city}",
    text="...", source="необязательная ссылка на факт",
    choices=[
        ("Текст варианта", "короткий тег", "следующий_узел", эффект_или_None),
    ],
),
```

`эффект` — функция `lambda s: s.add("voice", 1)` или `s.set("joined", True)`,
меняющая состояние игрока. `следующий_узел` может быть строкой или функцией
`lambda s: ...`, если переход зависит от накопленных флагов.

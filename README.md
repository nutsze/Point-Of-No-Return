# 2030: Точка невозврата

Документальная политическая визуальная новелла и симулятор на Python/pygame. Кампания начинается 20 августа 2020 года и содержит 12 глав, 36 решений, восемь регионов и девять достижимых концовок.

Первые девять глав описывают реальные события и содержат ссылки на источники. Гражданский совет, решения игрока и события после 2024 года вымышлены. После первого решения игра постоянно показывает пометку «АЛЬТЕРНАТИВНАЯ ИСТОРИЯ — события развиваются иначе, чем в действительности».

## Запуск Windows-версии

1. Распакуйте архив.
2. Запустите `2030_Точка_невозврата.exe` двойным щелчком.
3. Python и дополнительные библиотеки не требуются.

Поддерживаются 64-разрядные Windows 10 и Windows 11. Все рабочие фотографии, шрифты и сценарные данные находятся внутри EXE. Игра работает без интернета; сеть используется только после явного нажатия кнопки открытия источника или лицензии.

Сохранение создаётся автоматически после каждого решения:

`%APPDATA%\PointOfNoReturn\autosave.json`

При критической ошибке собранная версия записывает `crash.log` в тот же каталог.

## Управление

- Мышь — выбор кнопок и прокрутка.
- 1 / 2 / 3 — выбор решения в главе.
- Стрелки или Tab — переход между кнопками.
- Enter или Space — подтверждение.
- Esc — пауза или возврат.
- F11 — полноэкранный режим.
- Ctrl+S — ручное сохранение.
- Page Up / Page Down — прокрутка длинных списков.

## Запуск из исходников

Требуется Python 3.11 или новее:

```bat
py -3.11 -m pip install -r requirements.txt
py -3.11 bootstrap_assets.py
py -3.11 main.py
```

`bootstrap_assets.py` одноразово восстанавливает отсутствующие фотографии и шрифты из точных страниц Wikimedia Commons и официального релиза DejaVu, сверяя контрольные суммы уже проверенных ресурсов. После этого игра работает офлайн. Проверка без загрузки: `py -3.11 bootstrap_assets.py --check`.

На Linux или macOS используйте соответствующую команду `python3` вместо `py -3.11`.

## Сборка EXE

На 64-разрядной Windows с Python 3.11:

```bat
build_windows.bat
```

Готовый файл появится как `dist\PointOfNoReturn2030.exe`. Спецификация `point_of_no_return.spec` включает рабочие фотографии, шрифты, сценарий и лицензионные метаданные. Неоптимизированные PNG-копии оригиналов не включаются в EXE, но сохранены в архиве исходников.

## Проверка

```bat
py -3.11 -m unittest discover -s tests -v
```

Тесты проверяют структуру сценария, достижимость всех концовок, ограничения показателей, сохранение и восстановление, локальную медиатеку и масштабирование изображений.

## Фотографии и лицензии

В релиз включены девять локальных фотографий с проверенными страницами Wikimedia Commons. Полные сведения находятся в `assets/credits.json` и на экране «Авторы и источники»: название, автор, дата, первоначальный источник, прямая ссылка, лицензия, условия использования и описание изменений.

В игре выводится подпись «Фото: автор / Wikimedia Commons / лицензия». Рабочие JPEG уменьшены для интерфейса; временное масштабирование и кадрирование выполняются только при отображении. PNG-копии загруженных оригиналов находятся в `assets/originals/` в архиве исходников. Более ранние портреты датированы и не выдаются за фотографии событий 2020–2024 годов.

Если проверенная фотография отсутствует, интерфейс показывает нейтральную текстовую архивную карточку. Искусственно созданные изображения реальных политиков не используются. Фотографии информационных агентств, стоков и материалы с неизвестным автором или лицензией в релиз не включены.

Лицензия локальных шрифтов DejaVu сохранена в `assets/fonts/LICENSE-DejaVu.txt`.

## Структура

- `main.py` — экраны, ввод и игровой цикл pygame.
- `engine.py` — показатели, регионы, решения, концовки и сохранения.
- `media.py` — проверка и загрузка локальной медиатеки.
- `ui.py` — документальный интерфейс.
- `data/events.json` — события, источники и решения.
- `assets/credits.json` — метаданные фотографий.
- `tests/` — автоматические проверки.

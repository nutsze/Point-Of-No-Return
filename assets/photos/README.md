# Фото в игре

Все изображения — свободно лицензированные фотографии с Wikimedia Commons,
обработанные в монохромный затемнённый вариант для использования как фон
сцены (контент и личности не изменены — только кадрирование, ч/б, контраст
и виньетка, см. `credits.json`). Полная атрибуция (автор, лицензия, ссылка
на страницу файла) — в `credits.json` и выводится прямо в игре в углу экрана.

файлом просто показывает обычный тёмный фон без фото — это штатный случай,
не баг.

## Как добавить оставшиеся фото

```bash
pip install pillow
python3 tools/fetch_photos.py
```

Скрипт докачает только то, чего ещё нет в `credits.json`, обработает и
впишет атрибуцию. Список и точные ссылки на файлы — в `CHOSEN` внутри
`tools/fetch_photos.py`.
